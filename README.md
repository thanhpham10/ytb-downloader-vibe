# YouTube MP3 Downloader 🎵

A bulk YouTube to MP3 downloader with an intuitive UI, fast multi-threaded downloads, and built-in bypasses for YouTube's bot detection.

## 🚀 How to use
1. Download the `YtMp3Downloader.exe` from the `abs` folder (or Releases).
2. Open the app, paste your YouTube links (one per line).
3. Select your save directory and click **Let's go**.

## 🍪 Advanced: Fixing Download Errors by lack of cookies
1. Install the **Get cookies.txt LOCALLY** extension for your browser (Chrome, Edge, or Firefox).
2. Go to YouTube and make sure you are logged into your account.
3. Click the extension icon to export and download your cookies.
4. Make sure the file is named `cookies.txt` and place it in the **same folder** as `YtMp3Downloader.exe`.
5. Restart the app and try downloading again.

# Hướng dẫn sử dụng 

Ứng dụng tải nhạc MP3 hàng loạt từ YouTube với giao diện trực quan, tốc độ cao (đa luồng) và có sẵn cơ chế vượt rào chặn bot của YouTube.

## 🚀 Cách sử dụng cơ bản
1. Tải file `YtMp3Downloader.exe` (trong thư mục `abs`) về máy.
2. Mở ứng dụng lên, dán link YouTube cần tải (mỗi link 1 dòng).
3. Chọn thư mục lưu (Save) và nhấn nút **Let's go**.

## 🍪  Khắc phục lỗi không tải được do cookies 
1. Cài đặt tiện ích mở rộng **Get cookies.txt LOCALLY** trên trình duyệt Chrome, Edge, hoặc Firefox của bạn.
2. Mở một tab YouTube và đảm bảo bạn đã đăng nhập tài khoản của mình.
3. Bấm vào icon của tiện ích để tải file cookie về máy.
4. Đảm bảo file được đặt tên là `cookies.txt` và di chuyển nó vào **nằm chung thư mục** với file ứng dụng `YtMp3Downloader.exe`.
5. Khởi động lại ứng dụng và bắt đầu tải xuống (phần mềm sẽ tự động nhận diện tài khoản của bạn thông qua file text đó).
